# Emojiaineisto

Emojivalitsimen, emojihaun ja emojiehdotusten aineisto
`app/src/main/assets/emoji.tsv` on koottu Unicoden avoimista lähteistä skriptillä
`tools/emojidata.py`:

- emojit ja järjestys: [emoji-test.txt](https://unicode.org/Public/emoji/latest/emoji-test.txt)
- suomenkieliset nimet ja avainsanat: Unicode CLDR
  [annotations/fi.xml](https://github.com/unicode-org/cldr/blob/main/common/annotations/fi.xml) ja
  [annotationsDerived/fi.xml](https://github.com/unicode-org/cldr/blob/main/common/annotationsDerived/fi.xml)
